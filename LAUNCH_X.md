SettleIQ is now open source. 🧵

1/ SettleIQ is an open-source financial reconciliation platform. We built it because month-end reconciliation shouldn't require expensive enterprise software or manual spreadsheets.

2/ What it does:
- Matches charges, fees, refunds, and payouts with exact decimal arithmetic (no float errors)
- Classifies 7 types of discrepancies (amount breaks, timing breaks, phantom records, ambiguous matches)
- Provides visual transaction traces showing the complete money journey
- Maintains a hash-chained audit journal (tamper-evident)
- Exports JSON/CSV
- Full REST API for developers
