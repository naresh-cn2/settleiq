# SettleIQ — Open-source reconciliation engine for finance teams

**SettleIQ** is an open-source financial reconciliation platform. We built it because month-end reconciliation shouldn't require expensive enterprise software or manual spreadsheets.

## What it does

SettleIQ matches payment transactions, processor payouts, and bank deposits with exact decimal arithmetic. It identifies:
- Successfully matched records
- Missing payments (phantom processor/bank)
- Incorrect amounts (amount breaks)
- Unexpected fees (net/gross breaks)
- Timing differences (settlement lag)
- Duplicate or ambiguous transactions
- Unexplained discrepancies

## Key features

- Exact decimal arithmetic (no float errors)
- Constituent-level payout decomposition
- 7 discrepancy types with severity classification
- Visual transaction traces
- Evidence-backed investigation hypotheses
- Hash-chained audit journal
- JSON and CSV export
- Full REST API
